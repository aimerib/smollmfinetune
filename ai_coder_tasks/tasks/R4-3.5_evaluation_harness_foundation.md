## Goal
Establish basic evaluation infrastructure early in the development process to enable continuous testing and validation of model improvements.

## Context
Moving evaluation infrastructure earlier in the pipeline allows us to track progress and catch regressions as we build the Narrative Engine. This provides the foundation for more sophisticated evaluation in R4-9.

## Acceptance Criteria
### Core Infrastructure:
- [ ] A directory `narrative_engine/evaluation/` is created with basic structure
- [ ] A main script `scripts/run_basic_evaluation.py` that can evaluate any model checkpoint
- [ ] Simple JSON logging of evaluation results with timestamps

### Essential Evaluations:
- [ ] `eval_basic_generation.py`: Tests that model can generate coherent text
- [ ] `eval_dual_head_sanity.py`: Verifies both heads produce valid outputs
- [ ] `eval_training_progress.py`: Tracks loss curves and convergence metrics

### Integration:
- [ ] Evaluation runs automatically after each training checkpoint
- [ ] Results are logged to wandb alongside training metrics
- [ ] Simple pass/fail criteria for blocking bad checkpoints

## Implementation Notes
```text
• Keep evaluations simple and fast (<5 min runtime)
• Focus on catching obvious failures rather than nuanced quality
• Use synthetic test data for reproducible results
• Design for easy extension in R4-9
```

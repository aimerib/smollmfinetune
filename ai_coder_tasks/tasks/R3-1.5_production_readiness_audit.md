## Goal
Ship the Devkit as a polished, deployable SaaS that can sustain paying users and generate reliable telemetry before investing in R4 research.

## Context
Expensive model R&D only makes sense once the existing platform can attract and retain creators. This task performs a full production-grade hardening pass—infra, UX, performance, security, business metrics—backed by automated tests and CI gates.

## Acceptance Criteria
### Infrastructure
- [ ] Dockerfile multi-stage build produces <1 GB image; `docker-compose.prod.yml` spins app + redis + db.
- [ ] Healthcheck endpoint `/health` returns 200 & DB connectivity; readiness probe for k8s.
- [ ] Graceful shutdown: SIGTERM flushes background Celery jobs.
- [ ] Horizontal-scaling guide in `docs/deploy.md` with resource limits.

### UX Polish
- [ ] Global error boundary shows friendly message & logs to Sentry.
- [ ] All long ops show `st.spinner` / progress bar.
- [ ] Responsive layout verified via playwright tests at 390 px mobile width.
- [ ] Keyboard shortcuts: `⌘+S` saves character; ARIA labels added (axe-core score ≥90).

### Performance
- [ ] Pydantic settings tuned queries: 95th-pct page load <1.5 s (lighthouse).
- [ ] Redis cache layer for character synthesis reduces OpenAI calls by ≥70 %.
- [ ] Large file uploads chunked with tus-py client.
- [ ] Celery queue handles >50 concurrent training jobs; metrics in Prometheus.

### Security & Compliance
- [ ] All external input validated; Bandit scan score A.
- [ ] FastAPI rate limit middleware (`slowapi`): 60 req/min/user.
- [ ] OAuth2 login with JWT; roles admin/creator.
- [ ] NSFW toggle enforces image blur & content warnings.
- [ ] GDPR endpoints: `/me/export`, `/me/delete` with unit tests.

### Business Metrics
- [ ] Mixpanel (or PostHog) integrated; funnels: onboarding, dataset generation, training.
- [ ] Daily report job writes KPIs to `analytics.db` & pushes to Slack.
- [ ] Cost dashboard combines AWS billing + openai usage < `COST_BUDGET` env.

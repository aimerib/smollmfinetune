## Implementation Pattern

### Extract Template:
```python

📄 [Page Name] Page

Description of what this page does.
Extracted from main app.py for better maintainability.
"""

import streamlit as st
# Import only what this page needs
from typing import Dict, Any
import pandas as pd
# etc.

def page_[name]():
    """[Page description]"""
    
    # Ensure required managers are available
    if 'required_manager' not in st.session_state:
        st.error("Required manager not initialized. Please restart the application.")
        return
    
    # Page implementation...

# Run the page function if this file is executed directly (for testing)
if __name__ == "__main__":
    page_[name]()
```

### Routing Update in `app.py`:
```python
elif selected_page == "📄 Page Name":
    from pages.page_name import page_page_name

```

## Checklist / Steps

### For Each Page:
1. **Extract** - Copy function from `app.py` to new file in `/pages/`
2. **Clean Imports** - Add only necessary imports to new file
3. **Add Main Guard** - Add `if __name__ == "__main__":` block for testing
4. **Update Routing** - Modify `app.py` to import and call the new page
5. **Test** - Verify page works correctly in the app
6. **Remove** - Delete original function from `app.py`

### Order of Extraction (by complexity):
1. **model_testing.py** (simplest, good starting point)
2. **character_upload.py** (straightforward file upload)
3. **model_management.py** (file operations)
4. **training_dashboard.py** (visualization heavy)
5. **model_comparison.py** (complex UI logic)
6. **dataset_explorer.py** (data display logic)
7. **training_config.py** (lots of form logic)
8. **dataset_preview.py** (largest, most complex - save for last)

## Benefits
- **📦 Modularity**: Each page is self-contained and focused
- **👥 Collaboration**: Multiple developers can work on different pages
- **🧪 Testing**: Easier to write page-specific tests
- **🔧 Maintenance**: Smaller files are easier to understand and modify
- **🚀 Performance**: Potentially faster imports (only load what's needed)
- **📚 Documentation**: Each page becomes self-documenting

## Risks & Mitigation
- **Import Dependencies**: Carefully track what each page needs
  - *Mitigation*: Start with simple pages, test thoroughly
- **Session State**: Ensure all pages can access required managers
  - *Mitigation*: Follow established pattern from `world_management.py`
- **Breaking Changes**: Risk of introducing bugs during extraction
  - *Mitigation*: Extract one page at a time, test after each

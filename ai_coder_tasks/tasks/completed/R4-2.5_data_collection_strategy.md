## Goal
Establish a comprehensive data collection strategy that combines synthetic data generation for early training with pathways to real human conversation data.

## Context
The Narrative Engine needs high-quality training data that includes both conversational text and structured actions. Since this data format doesn't exist in large quantities, we need both synthetic generation and collection strategies.

## Acceptance Criteria
### Synthetic Data Generation:
- [ ] A script `scripts/generate_synthetic_conversations.py` creates training data
- [ ] Synthetic conversations include both text and action channels properly tagged
- [ ] Generated data covers diverse scenarios: dialogue, tool use, memory references
- [ ] Configurable generation parameters (length, complexity, action frequency)

### Real Data Collection Infrastructure:
- [ ] A simple data collection interface for capturing human conversations
- [ ] Annotation tools for marking up existing conversations with action tags
- [ ] Data validation pipeline to ensure schema compliance
- [ ] Privacy and consent handling for user-generated content

### Data Quality & Curation:
- [ ] Automated quality scoring for synthetic and real data
- [ ] Duplicate detection and removal
- [ ] Balanced dataset creation (text vs action examples)
- [ ] Export to unified dataset format (R4-2)

## Implementation Notes
```text
• Start with 100% synthetic data for initial training
• Use LLMs (OpenAI/Anthropic) to generate seed conversations
• Create templates for common interaction patterns
• Build towards human data collection gradually
• Ensure all data follows the unified schema from R4-2
```

## Checklist / Steps
1. Design conversation templates and patterns
2. Build synthetic data generation with LLM APIs
3. Create validation pipeline for generated data
4. Develop simple annotation interface
5. Implement quality scoring metrics
6. Test data with prototype models
7. Create data versioning and tracking system

## Goal
Create the main gameplay interface where players interact with their selected characters in the chosen world. This is where the "magic happens" - the actual conversation and narrative experience that players came for.

## Context
This is the **platform runtime** - different from both the devkit runtime (R2-3) and cartridge runtime (R2-1). Players have selected a world, chosen characters, and now want to start playing. This is the equivalent of Steam's game interface, Character.ai's chat, or a VR world where players interact with NPCs.

## Acceptance Criteria

### 1. Session Runtime Engine
- [ ] `PlatformRuntimeEngine` class that manages active play sessions
- [ ] Integration with R2-2 `RuntimePromptConstructor` for multi-character prompting
- [ ] Real-time character state management: moods, relationships, memory
- [ ] Session persistence: auto-save conversations, character states, world events

### 2. Multi-Character Chat Interface (`/play/{session_id}`)
- [ ] **Main Chat Area**: Conversation thread with multiple characters
- [ ] **Character Panel**: Show active characters with portraits, names, current mood
- [ ] **World Context Strip**: Current location, time, weather, recent events
- [ ] **Player Controls**: Send messages, trigger world events, manage scene
- [ ] **Character Switching**: Toggle between group chat and 1-on-1 conversations

### 3. Advanced Interaction Features
- [ ] **Group Conversations**: Characters can talk to each other, not just the player
- [ ] **Character Memory**: Each character remembers past interactions across sessions  
- [ ] **Mood Dynamics**: Character moods change based on conversation flow
- [ ] **World Events**: Random or triggered events that affect all characters
- [ ] **Relationship Tracking**: Characters develop relationships with player and each other

### 4. Runtime Controls & Settings
- [ ] **Session Management**: Pause, save, export conversation history
- [ ] **Character Controls**: Temporarily mute characters, adjust personality sliders
- [ ] **World Controls**: Change time/weather, trigger custom events
- [ ] **Generation Settings**: Temperature, max tokens, response style per character
- [ ] **Session Sharing**: Share interesting conversations with friends (privacy controls)

### 5. Performance & Scalability
- [ ] **Concurrent Generation**: Multiple characters can generate responses simultaneously
- [ ] **Streaming Responses**: Real-time text streaming for each character
- [ ] **Background Processing**: Character state updates happen asynchronously
- [ ] **Session Recovery**: Resume sessions after connection drops or browser closes
- [ ] **Mobile Optimization**: Touch-friendly interface, responsive design

## Example User Flow
1. **Launch Session** → loads "My Fantasy Adventure" with Wizard & Bard
2. **Player sends message** → "I need help finding the ancient artifact"
3. **Both characters respond** → Wizard offers knowledge, Bard suggests tavern gossip
4. **Characters interact** → Wizard and Bard discuss different approaches
5. **Player continues** → chooses Bard's suggestion, relationship with Bard improves
6. **World event triggers** → sudden rainstorm affects everyone's mood
7. **Session auto-saves** → player can resume later from this exact point

## Technical Innovation: The C.L.A.R.A. Loop

The breakthrough insight: characters need **limbic system processing** alongside conscious generation:

1. **Generation Head**: Produces conversational responses (conscious thought)
2. **Control Head**: Emits emotional/cognitive state tokens (subconscious processing)  
3. **Recirculation**: Control tokens from turn N become context for turn N+1
4. **UI Integration**: Same control tokens drive interface changes

**Example Flow:**
```
User: *pats character on head*
Control Head: <mood_happy><relationship_affinity_1><blush>
Generation Head: "Aww, that's sweet of you!"
Next Turn Context: Previous tokens influence warmer, more affectionate responses
UI Updates: Character avatar blushes, relationship indicator increases
```
